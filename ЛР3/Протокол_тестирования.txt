Протокол тестирования MiniList<T>
Лабораторная работа №3. Интерфейсы IEnumerable<T>, IEnumerator<T>, IEnumerable, IEnumerator.

План
1. Пустой список: MoveNext возвращает false, чтение Current до начала запрещено.
2. Append вставляет в голову: порядок перебора обратный порядку добавления, номера узлов возрастают.
3. Обобщённый foreach и необобщённый foreach дают одну и ту же последовательность.
4. Reset возвращает перечислитель в исходное положение, повторный проход совпадает с первым.
5. Current после завершения перебора запрещён; лишние MoveNext остаются false.
6. Dispose не выбрасывает исключение. Два перечислителя одного списка независимы.

Результаты
  [+] Пустой список: Current до MoveNext
  [+] Пустой список: MoveNext == false
  [+] Пустой список: Current после MoveNext
  [+] Append возвращает возрастающие номера
  [+] Голова списка — последний добавленный элемент
  [+] Второй узел хранит предыдущий элемент
  [+] Хвост хранит первый элемент и не имеет продолжения
  [+] Обобщённый foreach: 3, 2, 1
  [+] Необобщённый foreach совпадает с обобщённым
  [+] IEnumerator.Current возвращает тот же объект, что и обобщённый Current
  [+] Первый MoveNext
  [+] Второй MoveNext
  [+] После Reset чтение Current запрещено
  [+] После Reset проход повторяется
  [+] Повторный MoveNext за последним элементом == false
  [+] Ещё один MoveNext остаётся false
  [+] Current после завершения запрещён
  [+] Два перечислителя независимы
  [+] Dispose не выбрасывает исключение

Итог: пройдено 19, не пройдено 0.

Заключение
MiniList<T> строит односвязный список с вставкой в голову и отдаёт элементы через обобщённый и необобщённый перечислители. Контракт Current, MoveNext, Reset и Dispose выполняется на пустом списке, на списке из нескольких узлов и при повторном проходе. Реализация интерфейсов пригодна для перебора коллекции в приложении.
